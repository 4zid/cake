# Mails en HTML

Código listo para pegar en MailerLite (editor de HTML personalizado). Las imágenes salen de https://cuantocobro.app/email/. Para cambiar textos, edita `armar.py` y corre `python3 docs/mails/armar.py`.

| Archivo | Asunto | Vista previa |
| --- | --- | --- |
| `1-entrega.html` | Tu acceso a Cuánto Cobro 🎂 | Tu código y el link para empezar ahora mismo. |
| `2-primeros-pasos.html` | Tu primera torta con precio justo (5 minutos) | Tres pasos para saber cuánto cobrar tu próxima torta. |
| `3-tu-opinion.html` | ¿Te sirvió? (me ayuda muchísimo) | Dos líneas tuyas ayudan a otras pasteleras a cobrar mejor. |
| `4-proxima-app.html` | ¿Qué te gustaría que haga ahora? | Estoy armando la próxima herramienta y quiero que la elijas tú. |
